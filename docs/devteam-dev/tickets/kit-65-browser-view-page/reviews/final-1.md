## What I tried to break, and how it held

1. **Typed or pasted text kept after send.** In the source, input lives only in handler locals. `held` keeps only key names of non-printable keys and chords, and is cleared on keyup, blur and reconnect. `queued` holds only mouse moves. The page uses no storage, `console`, `history`, `postMessage` or `onerror` reporter. The closure walk is real: a typed char kept in a closure `let` (M1) and a paste kept in a `Map` (M2) each fail "nothing typed is kept". A queue flushed on open (M3b) fails "goes nowhere else". A queue flushed lazily on the next send (M3) passes every test: that is **F1**. A Promise or `history.state` holding input passes too (**F3**).
2. **Origins.** The CSP is `default-src 'none'`, with the script and style pinned by hash (the test recomputes them), `connect-src 'self'`, `img-src 'none'`, `base-uri 'none'` and `form-action 'none'`. The socket URL is built only from `location.protocol` and `location.host` plus `/socket`, with no wildcard and nothing taken from a message. The page adds no global and has no `message` listener; a cross-origin framer gets a SecurityError. Referrer is `no-referrer`. Framing is left to the server (**F5**).
3. **Address bar.** Tested `toNav` against 31 hostile inputs (javascript: in any case and with leading whitespace, vbscript:, view-source:, blob:, filesystem:, chrome-extension:, intent:, ftp:, ws:, about:blank, about:srcdoc, data:, file:, chrome:, devtools:, embedded NUL and tab). Each one is refused, or becomes an `https://` host:port (`javascript:0` becomes `https://javascript:0`, which is harmless). Mutating the protocol check fails the address-bar test (M6). The page can't navigate itself: the form's submit is prevented and backed by `form-action 'none'`, and the page has no links and no `location` writes. Raw versus parsed URL is noted in **F4**.
4. **Messages.** Every outgoing shape is closed and within the schema's bounds: x and y clamped to the frame (at most 8192), wheel deltas clamped to ±100000, `key` and `code` at most 32, `text` a single code point, paste pieces at most 10000 UTF-16 units cut off surrogates, nav at most 2048, and `mods` omitted when 0. A stray field on `paste` (M8) fails the paste test, because every message is checked with `check.mjs`. Incoming: `closed()` rejects extra keys, including an own `__proto__`. `url` must match x-masked-url and is set via `.value`, `why` via `textContent`, and `held` shows only two fixed strings. `why` as `innerHTML` (M7) fails the bye test.
5. **No Done or hand-back.** The page has no such control in any state; the test checks the dialog-open and bye states too. Sign out opens a modal whose default focus is Cancel. Cancel and Escape send nothing, and only the confirm sends `{t:"forget"}`. It does nothing else, but it does that silently when there is no socket (**F2**).

Not defended by the page (noted, out of its reach): a hostile or compromised server (kit-66 runs as the agent and receives everything), an extension or devtools in the owner's browser, framing and Origin checks (kit-66), and ReDoS or huge frames from the server (it is trusted).
