# Spec review, pass 1

- Reviewer: spec-reviewer (fresh subagent, claude-opus)
- Reviewed: 79816da24b691cd2ad26fe1dd2696fcf9a958f7d (spec.md)

I read the spec, `ticket show kit-46-standalone-hub` (the final done_when set, with the `(image)` form), the design's `devteam.mjs (kit-46)` bullets, Contracts, Boot, Failure modes, Testing and Security, and the code at 79816da: the re-exec block (~37-47), `homeAt`/`machineWide`, `mainRoot`, `devteamDir`, `runDir` (~424-470), `runOwnerAction` (~11728), `startHub` (~11794-11910), the operator pane lookup (~13206), `machineStatus`'s hub line, `cmdDashboard`'s handlers (~13763), the role guard at dispatch (~19093), `kitVersion` (~18072), and the hub fixtures in test/operator-threads.test.mjs and test/lib/kit.mjs.

Every done-when is restated, and the restatements are faithful. The spec follows the design: `--release` comes only from the boot, `DEVTEAM_KIT_RELEASE` is never read, the skip applies only when the variable equals the hub port, and there are five hub lines. Reusing `startHub` whole keeps every press check (own Host, Sec-Fetch-Site plus Origin, the gateway signature, the in-memory nonce, and the child's re-check against the store). I found no security hole in the move itself. The one defect that blocks approval is F1. It is a path-resolution gap: on the box `mainRoot` and `runDir` become the cwd, but in the tests they resolve to the kit's git checkout. So the "writes nothing under run/" check cannot fail as specified.

Values and refusals:
- P1 harness-agnostic: no harness is involved. Passes.
- P2 nothing project-specific: generic machine command and ENV names. Passes.
- P3 decide and report: the bad-`--release` call is made and recorded ("My call"). Passes.
- P4 owner-only asks: none asked. Passes.
- P5 adversarial for authority: risk high, and check 4 tries an unsigned press, a reused nonce and a foreign Origin. It does not try a foreign Host or Sec-Fetch-Site against the standalone hub (F5). Partly passes.
- P6 keep it simple and name what isn't defended: the design names it, but the spec has no Security line (F10). Minor.
- R1 no self-widening of authority: presses still need the gateway's signature on a box, and nothing new writes owner lines. Passes.
- R2 owner-facing plain words: the new lines are operator- and log-facing and readable. Passes.
