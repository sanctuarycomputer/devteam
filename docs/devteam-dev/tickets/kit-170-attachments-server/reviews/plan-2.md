- **P9 (Minor, wont-fix): sound.** The Host check is a defence against DNS rebinding. A rebound page sends the attacker's own name as Host, which matches none of `127.0.0.1:<port>`, `localhost:<port>` or `<--host>:<port>`. A client that isn't a browser can set any Host it likes, so narrowing the list would not keep LAN clients off a dashboard the owner chose to bind with `--host`. Only binding decides that. The default `host` is `127.0.0.1`, so out of the box the done-when's two names are exactly what is accepted. Keeping the one check that every route uses (line 16218) avoids splitting the definition of "its own address". The point is recorded in the plan's Notes and put to the supervisor with approve-plan. That is the right channel for reading the done-when this way.
