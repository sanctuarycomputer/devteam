# Sample project

A small `project/` folder showing what planning produces: one column plan and five graph nodes with a contract node, three parallel builds and an integration node. Run the scripts against it with `--project`:

```
node docs/devteam/scripts/devteam.mjs validate --project docs/devteam/examples/sample-project
node docs/devteam/scripts/devteam.mjs waves --project docs/devteam/examples/sample-project
```
